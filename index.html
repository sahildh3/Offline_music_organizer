Streaming ZIP

Best for: Large libraries (100+ songs). Uses the Web Streams API to build the ZIP file in real-time, keeping memory usage low and preventing browser crashes.

  • Low RAM consumption
  • Single file download
  • Reliable for large exports
Batched ZIPs

Best for: Very small libraries. Splits the export into manageable 300MB parts.

  • Limited to files < 300MB
  • Limited to total library < 1GB
  • Uses more memory than streaming
Direct Sync

Best for: Power users. Writes files directly into your chosen directory. No ZIP file is created, so your music is organized instantly on your hard drive.

  • Instant organization
  • No intermediate ZIP file
  • Native file system performance
Experimental Feature

ZIP Format Limits

Standard ZIP files are limited to 4GB. If your export exceeds this, the archive may be corrupted. Please split large libraries.
